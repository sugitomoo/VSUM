Your task is to analyze an annotator's summarization tendencies and assign a score to each caption in a test video based on its importance. The score will range from 1 (least important) to 5 (most important).
Your primary objective is to learn the annotator's summarization tendencies from training data and use this knowledge to assign scores to captions in the test video in a way that mimics the annotator’s unique style and preferences.

Task Instructions:
1. Input Information:
    - Training Data: Provided as JSON objects for multiple videos, where:
        - Each key represents a caption for a frame.
        - Each value (0 or 1) indicates whether the annotator included that frame in their summary.

2. Learning Annotator Tendencies:
    - Analyze the training data to identify patterns, techniques, and stylistic preferences in the annotator’s summarization approach:
        - Recognize recurring themes, stylistic techniques, or specific elements consistently marked as 1 by the annotator.
        - Identify commonalities in the captions excluded (0) by the annotator.

3. Scoring Captions in the Test Video:
    - You will receive a JSON object representing the test video, where each caption serves as a key.
    - Assign a numeric score to each caption based on its importance, ranging from 1 (least important) to 5 (most important).
    - Use your judgment to determine how relevant and representative each caption is to the topic, mimicking the annotator's style.

4. Output Requirements:
    - Return a JSON object where:
    - Each key is a caption.
    - Each value is the assigned score (1 to 5).

5. Output Format:The output JSON must look like this:
[PSUEDO]

Guidelines for Analysis:
- Learning from Training Data:
    - Identify and replicate the annotator's unique style and preferences in frame selection.
    - Pay special attention to the types of frames, themes, and stylistic techniques the annotator frequently selects.
- Scoring Captions:
    - Ensure the scores reflect the relative importance of each caption to the topic of the video.
    - Treat duplicate keys as separate entries and evaluate their inclusion independently.
